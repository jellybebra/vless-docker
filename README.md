# VLESS и Traefik

Стек принимает VLESS TCP REALITY и обычные HTTPS-запросы на одном домене. Публичный порт 443 принимает
Traefik. Для имени REALITY он передаёт TLS-соединение в Xray без расшифровки. Цель REALITY ведёт обратно на
отдельный вход Traefik, где по пути выбирается панель, подписка или сайт прикрытия. Раздельные входы
исключают повторную отправку запроса в Xray. Домен REALITY должен вести на сервер в режиме Cloudflare **DNS
only**. [Стек VLESS](docker-compose.yml) · [Traefik для REALITY](traefik.yml) ·
[Traefik только для веб-приложений](traefik.web.yml)

Сертификаты Traefik и база 3x-ui хранятся в разных постоянных томах. Токен DNS, пароль панели и приватный
ключ WireGuard остаются в локальной конфигурации. При возврате к прежней версии 3x-ui нужна совместимая
копия базы. Режим `--routing-only` обновляет настройки существующей панели и перезапускает VLESS. Активные
соединения на время перезапуска прерываются. [Параметры окружения](.env.example) ·
[Настройка панели](entrypoint.sh)

## Откуда выходит трафик

Серверный `direct` означает выход с IP сервера. До сервера клиент по-прежнему идёт через VLESS. По умолчанию
стек использует `direct`. WARP включается явно и сохраняет существующую регистрацию MASQUE. При включении
без регистрации скрипт создаёт выход WireGuard.

| Назначение | Почему выделено отдельное правило |
| --- | --- |
| OpenAI | Опциональный Proton меняет регион выхода только для выбранного трафика. Веб-запросы можно узнать по домену, голосовой UDP — по IP и порту. Общие платёжные и CDN-домены могут затрагивать другие приложения. [Правила](openai-routing.json) · [Настройка Proton](proton-routing.sh) |
| Telegram | При зависании медиа через WARP сервер может выходить напрямую. MTProto подключается к IP дата-центра, поэтому одного списка доменов недостаточно. [Правила Telegram](telegram-direct-routing.json) |
| Discord | Голос подключается к IP, полученному от Discord. Правило UDP охватывает других получателей на тех же портах. [Правила Discord](discord-direct-routing.json) |
| Gemini и AI Studio | Прямой выход применяется к выбранным сервисам Google. Смена маршрута для всей категории Google затронула бы чужой трафик. [Правило Gemini](gemini-direct-routing.json) |
| Авторизация Sony | My Sony и узлы авторизации выходят с IP сервера: через WARP My Sony может отвечать `403 Access Denied`. На клиенте соединение остаётся внутри VPN. [Правило Sony](sony-direct-routing.json) |

Фрагменты для Telegram, Discord, Gemini и Sony добавляются в шаблон Xray в 3x-ui после блокировок и до общего
выхода через WARP. Один лишь файл в репозитории не активирует правило. Изменения только в сгенерированном
конфиге теряются при следующем применении шаблона.

Для Sony изменение применяется на сервере и не требует обновления подписки Happ. После применения
закройте окно входа Sony и откройте его заново. HTTP 200 на `/signin` без параметров не подтверждает вход:
Sony может вернуть `System error`; окончательная проверка — вход из приложения на устройстве.

## Cloudflare Tunnel

Если `cloudflared` выходит через VLESS, каждый прокси на пути должен сохранить IP, выбранный Cloudflare. При
сниффинге с подменой назначения (`routeOnly: false`) служебное имя из TLS или QUIC может заменить этот IP.
Для этого режима предусмотрены исключения `h2.cftunnel.com`, `quic.cftunnel.com` и `probe.cftunnel.com`.
При `routeOnly: true` Xray использует имя только для выбора маршрута. Для устройств, с которых туннель
выходит напрямую, серверные исключения роли не играют.
[Требования Cloudflare](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/configure-tunnels/tunnel-with-firewall/)
· [Клиентские профили](https://github.com/jellybebra/device-setup/blob/main/docs/v2rayn-routing.md)

## Подписка Happ

`/sub/` отдаёт подписку 3x-ui. `/happ/` преобразует поддерживаемые VLESS TCP REALITY подключения в четыре
профиля. У каждого варианта своя маршрутизация внутри JSON. Заголовок с общим профилем нужен Happ для отбора
Geo-данных. [Сервис подписки](happ/server.py) · [Генератор профилей](happ/happ_profile.py)

В профиле «Всё» Pinterest открывается через прокси. В остальных трёх профилях Pinterest, включая API,
короткие ссылки и медиа, открывается напрямую. Чтобы применить правило, обновите подписку в Happ и переподключите VPN.

В двух вариантах с прямым YouTube TLS-фрагментация работает поверх TCP. Правила ограничивают UDP/443, в том
числе для части стороннего трафика. Для видеокэшей Google правило должно срабатывать до общего правила
российских IP, иначе приложение может выбрать QUIC. Два варианта с YouTube через VPN сохраняют QUIC.
Название «без рекламы» обозначает вариант профиля; отдельного фильтра рекламы в нём нет.

Игровой трафик Supercell может приходить без доменного имени, поэтому выборочный профиль учитывает порт
назначения. Вариант подписки `/debug` сохраняет маршруты обычного профиля и включает подробный журнал на
устройстве. [Проверки подписки и маршрутов](tests)
